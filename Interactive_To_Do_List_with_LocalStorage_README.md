# Interactive To-Do List with LocalStorage

## Overview
An interactive To-Do List web application that helps users manage daily tasks. Users can add, edit, delete, and mark tasks as completed. Tasks are stored in the browser using LocalStorage so the data remains available after refreshing the page.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Store tasks using LocalStorage
- Keep tasks after page refresh
- Responsive and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Project Requirements
- Create an interactive To-Do List.
- Use JavaScript for task operations.
- Use LocalStorage for data persistence.
- Provide a responsive user interface.

## Project Structure

```text
interactive-todo-list/
├── index.html

└── script.js
```

## How It Works
1. The user enters a task in the input field.
2. The task is added to the task list.
3. JavaScript stores the task data in LocalStorage.
4. Users can edit, delete, or mark tasks as completed.
5. When the page is refreshed, saved tasks are loaded from LocalStorage.

## Data Persistence
LocalStorage is used to save the task list in the browser. This allows the tasks to remain available even after the webpage is refreshed or reopened in the same browser.

## Design Decision
I chose a simple and responsive interface so users can easily add and manage their tasks. LocalStorage was used to provide persistent task data without requiring a database.
