Interactive To-Do List with LocalStorage

Overview

An interactive To-Do List web application that helps users manage their daily tasks easily. Users can add, edit, delete, and mark tasks as completed.

Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using LocalStorage
- Tasks remain saved after page refresh
- Simple and responsive user interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

How It Works

1. Enter a task in the input field.
2. Click the Add button to add the task.
3. Mark the task as completed when finished.
4. Edit or delete tasks whenever needed.
5. LocalStorage automatically saves the task data.

Data Persistence

LocalStorage is used to store the tasks in the browser. This allows the task list to remain available even after refreshing the webpage.

Design Decision

I chose a simple and responsive design so users can easily manage their tasks. LocalStorage was used to maintain task data without requiring a database.
